# Bài 1: Kiểm tra cài đặt Docker Engine và chạy Container Hello-World

## 1. Kiểm tra phiên bản Docker

**Lệnh thực hiện:**

```bash
docker version
```

**Kết quả:** Dán kết quả thực tế của lệnh `docker version` tại đây.

## 2. Kiểm tra thông tin Docker Engine

**Lệnh thực hiện:**

```bash
docker info
```

**Kết quả:** Dán kết quả thực tế của lệnh `docker info` tại đây.

## 3. Chạy Container Hello-World

**Lệnh thực hiện:**

```bash
docker run hello-world
```

**Kết quả:** Dán kết quả thực tế của lệnh `docker run hello-world` tại đây.

## 4. Kết luận

Đã thực hiện kiểm tra phiên bản Docker CLI, kiểm tra thông tin Docker Engine và chạy container `hello-world`. Khi xuất hiện thông báo `Hello from Docker!`, có thể xác nhận Docker hoạt động đúng theo yêu cầu của bài thực hành.ht
